Pour comprendre les drapeaux

Un drapeau est une marque dans l'en-tête d'un paquet TCP, qui indique son rôle dans la conversation. Dans les paquets, ils sont notés par une seule lettre : S pour SYN, A pour ACK, F pour FIN, R pour RST, P pour PSH. C'est ce qui rend une valeur comme AFPR illisible sans cette table.
