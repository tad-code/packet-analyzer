Que fait cet écran ?

Il lit les paquets qui passent sur une carte réseau de cette machine et les affiche au fur et à mesure. Chaque ligne du tableau est un paquet : un morceau de données envoyé d'une machine à une autre.

L'analyse en communications, l'explication en langage humain, la détection et l'enrichissement par une API arriveront dans les versions suivantes. Cette version se limite à capturer et afficher.

Que signifie chaque colonne ?
Source / Destination
Les adresses IP des deux machines qui échangent ce paquet. Une adresse 192.168.x.x ou 10.x.x.x est une adresse privée, interne au réseau local ; les autres sont publiques.
Protocole
TCP : communication fiable, avec ouverture et fermeture de connexion — c'est le cas du web. UDP : envoi sans connexion, plus rapide mais sans garantie — c'est le cas du DNS. ICMP : messages de contrôle du réseau, comme le ping.
Ports
Le port désigne le service visé sur la machine distante. Le port de gauche est celui de l'émetteur, celui de droite le service contacté.
Taille
Nombre d'octets du paquet, en-têtes compris. Additionnées, ces tailles donneront le volume échangé par une communication.
Service probable
Le service habituellement associé à ce port. C'est une indication, pas une certitude : le port 443 laisse penser à du HTTPS, mais rien n'empêche un autre service d'y répondre. Le contenu chiffré, lui, n'est jamais lu.
