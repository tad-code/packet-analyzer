Historique des captures

Chaque ligne correspond à une capture enregistrée : une session d'observation, avec son interface, sa date, et le nombre de communications qu'elle a révélées. Les paquets eux-mêmes ne sont pas conservés — une capture en produit des milliers, et seules les communications ont un sens d'analyse.

Ce qu'il faut faire

  1. Créer la clé secrète dans Supabase : Settings → API keys → Secret keys
  2. La coller dans le fichier .env, à la ligne SUPABASE_SECRET_KEY=
  3. Créer les tables : ouvrir SQL Editor, coller le contenu de sql/schema.sql, puis Run
  4. Redémarrer l'application.

Pourquoi la clé secrète et non la clé publique ? Parce que la sécurité par ligne est fermée sur ces tables. La clé publique, elle, est faite pour être publiée : l'autoriser à écrire rendrait la base effaçable par n'importe qui.

Que contient chaque colonne ?
Début
Instant auquel la capture a été lancée.
Interface
La carte réseau écoutée. Deux captures sur des interfaces différentes n'observent pas le même trafic.
Paquets
Nombre total de paquets vus. Il est plus élevé que ce que l'affichage montrait : le tampon de l'interface est limité, mais le compteur, lui, n'oublie rien.
Communications
Nombre de conversations distinctes observées. Cliquez pour voir le détail.
Volume
Somme des octets échangés dans toutes les communications de la capture.
